# Manshi Kumari Neha — Interactive Environmental Portfolio

## Stack
- React + Vite
- Tailwind CSS
- shadcn/ui-style primitives (`Button`, `Badge`, `Card`)
- Framer Motion
- Lucide React

No traditional hand-written component CSS is used. Styling is implemented with Tailwind utility classes.

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy
Deploy the generated `dist/` folder to Vercel, Netlify, Cloudflare Pages, GitHub Pages (with the appropriate SPA configuration), or another static host.

## Content
The portfolio content is based on the supplied resumes for Manshi Kumari Neha. It does not invent additional employers, metrics, certifications or project outcomes.


### Navigation
- Smooth section navigation without adding `#section` fragments to the browser URL.
- The MN logo and back-to-top control return to the top without changing the URL.
- “Let's connect” opens an animated contact dialog with direct email and phone actions.
